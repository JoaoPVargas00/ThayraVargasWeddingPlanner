# Tháyra Vargas Wedding Planner

Site institucional desenvolvido para a Tháyra Vargas Wedding Planner, com o objetivo de apresentar seus serviços de assessoria e organização de casamentos, divulgar eventos realizados e facilitar o contato com noivos que desejam transformar seus sonhos em uma celebração inesquecível.

O projeto possui uma identidade visual elegante, romântica e sofisticada, alinhada ao universo dos casamentos e eventos especiais.

⸻

Sobre o projeto

A plataforma apresenta o trabalho de Tháyra Vargas como wedding planner, destacando sua experiência no planejamento, organização e acompanhamento de casamentos.

O site foi criado para proporcionar uma navegação simples e agradável, permitindo que os noivos conheçam os serviços oferecidos, visualizem trabalhos realizados e entrem em contato para solicitar informações ou agendar uma reunião.

⸻

Funcionalidades

* Página inicial com apresentação profissional
* Seção sobre a wedding planner
* Apresentação dos serviços oferecidos
* Portfólio de casamentos e eventos realizados
* Galeria de fotos
* Depoimentos de clientes
* Botões de contato pelo WhatsApp
* Links para redes sociais
* Formulário de contato
* Menu responsivo para dispositivos móveis
* Animações durante a navegação
* Layout adaptado para computadores, tablets e celulares
